v0.15.1

QuickerAgent

- 在“设置 → Quicker 连接”中发现、检测并显式启用本机 Quicker 原生 MCP，默认关闭；只保存来源引用，不复制密钥，不修改 Quicker 的写入或审批设置。
- 每轮从实际连接重新获取 MCP 说明与工具目录，主 Agent 和子代理按实际允许的工具使用当前知识；缺失或超预算的说明保持明确状态。
- 完善变量改名、删除和未使用清理：在原文档内核验引用，共用一次撤销；失败保留草稿，并阻止保存、同步及步骤授权继续使用旧正文。
- 展示当前原生参数定义和 gateway YAML codec 指南的来源；刷新技能与文档知识，完善模型选择浮层的键盘和焦点操作。

CLI / 安装

- Agent 与 qkrpc 统一更新为 0.15.1，安装包包含静态 React 界面、独立 Node 服务及配套 CLI。
- 大模块 schema 支持带来源与修订核验的渐进读取，保留原始数值和完整性状态；连接变化或内容变化时拒绝拼接旧结果。

插件 / Quicker

- 发布 V1 quicker.rpc 与 V2 quicker.rpc.net10 0.15.1.0，包含当前模块定义来源及 schema 分页支持。
- V1 现有动作继续使用 YAML open/save、冲突检查和部分保存回执。
- V2 动作源编辑继续使用 Quicker 原生 MCP；qkrpc 的 V2 完整 source 读写仍关闭。连接检测只读取初始化说明和工具目录，不执行动作；此版不宣称跨聊天原生编辑工作集隔离。
