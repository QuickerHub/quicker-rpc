v0.15.0

QuickerAgent

- 工作台与菜单、浮层统一黑白灰深浅主题；迁入新版动作设计器，完善步骤、变量、动作引用与子程序调用编辑。
- 大参数使用页签编辑，共享草稿与文件写入状态；修复弹窗刷新、迟到请求及隐藏字段捕获键盘的问题。
- 生产运行改为静态 React、独立 Node Agent 服务和 Electron 壳；Next 保留开发 HMR 与显式兼容入口。
- Agent 从当前宿主重新获取模块知识与输入契约，保留来源、宿主身份、schema 修订和查询时间；未知能力保持未知。
- 更新本地编写指南与 YAML codec 自描述，文档刷新保留当前正文与引用；移除语音和剪贴板历史入口。

CLI / 安装

- qkrpc 与 QuickerAgent 统一为 0.15.0，修复发布流水线读取新版 release/build 版本文件的问题。
- 安装包随附 qkrpc CLI 和运行资源；保留独立资料目录、单写入者和进程归属保护。
- V1 现有动作用 action open → program.source.yaml/files → save dry-run → save 编辑，保留原生未知字段、版本检查与部分成功提示。

插件 / Quicker

- 正式发布 quicker.rpc 与 quicker.rpc.net10 0.15.0.0，供 V1 和 V2 下载使用，替代仅在测试机存在的 revision 包。
- 宿主连接保留 instance/session/endpoint 绑定，读取与写入不在断线后自动切换目标。
- 修复 V2 插件依赖隔离和启动、停止竞态；官方 Quicker V2 2.3.20 已验证模块知识及 notify、delay、runAction 原生输入契约。
- V1 YAML 保存、读回及原始正文恢复已真机验证；V2 完整 source 读写仍未开放，V2 动作源编辑继续使用 Quicker 原生 MCP。
